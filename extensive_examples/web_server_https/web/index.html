A web server, over TLS, written in FunnyLang.

Every byte of HTTP, every session, every page you are looking at was handled by a program written in a language with yap for print. The TLS underneath is your operating system's own.

TLS 1.2 or nothing

Forward-secret, authenticated ciphers only. Plain HTTP gets a redirect, never a page, and Strict-Transport-Security keeps it that way.

Two dozen threads

Twenty-four acceptors on real OS threads, each with its own event loop, and one keeper thread that owns everything shared. No locks anywhere in the FunnyLang.

FunnyLang all the way down

The HTTP parser, the router, sessions, CSRF, rate limits, SHA-256, base64 and JSON are all .funny files. Only the socket and the TLS record layer are not.
