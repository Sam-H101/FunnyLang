What this does, and does not

  • It downloads songs their owners chose to share publicly, using the URL the song's own public API advertises. It does not sign in and it carries no key.
  • There is no mp3. Suno serves the mp3 only to a signed-in owner, and the m4a it advertises publicly is encrypted. The mp4 is the one rendition that plays, so it is the default.
  • The song belongs to whoever made it. This saves a copy of a file that is already being served; what you do with it is between you, them, and Suno's terms.
  • Nothing here decrypts anything, and there is no code in it that tries.
