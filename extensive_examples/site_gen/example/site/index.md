This site is built by `site_gen`, which is about seven hundred lines of
FunnyLang and no dependencies at all.

It has [posts](/posts.html), and each post has its own page. Tags get pages
too, and there is an [Atom feed](/feed.xml).

## What is here

- Markdown with the everyday constructs
- A layout with holes in it
- Static files copied through

> A site generator is the smallest program that is still a real program:
> it reads files, transforms them, and writes files.
